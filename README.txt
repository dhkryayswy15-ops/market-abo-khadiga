ماركت أبو خديجة — تطبيق ويب تقدمي (PWA)

تشغيل سريع:
1) ارفع محتويات هذا المجلد إلى GitHub Pages أو أي استضافة HTTPS.
2) افتح رابط الموقع في Chrome على أندرويد، واسمح باستخدام الكاميرا.
3) من قائمة Chrome اختر "إضافة إلى الشاشة الرئيسية".

مهم: قراءة الكاميرا تتطلب HTTPS ومتصفحًا يدعم BarcodeDetector. إذا لم يدعمه المتصفح، يمكن إدخال الباركود يدويًا.

تفعيل المزامنة السحابية:
1) أنشئ مشروعًا في https://console.firebase.google.com/
2) أضف Web App وانسخ إعدادات firebaseConfig.
3) في Firestore Database أنشئ قاعدة بيانات.
4) استبدل القيم PUT_... داخل index.html بالقيم التي يعطيها Firebase.
5) اضبط قواعد Firestore بشكل آمن قبل استخدامه الفعلي. لا تترك قاعدة البيانات مفتوحة للعامة.

تنبيه: النسخة الحالية نموذج أولي. تخزين الوضع المحلي على الجهاز، أما مزامنة السحابة فتعمل بعد إعداد Firebase. لا تستخدمها كنظام مبيعات حقيقي قبل إعداد تسجيل الدخول وقواعد الصلاحيات والنسخ الاحتياطي.
